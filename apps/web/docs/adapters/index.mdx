An adapter connects `Files` to one storage backend. Each is its own subpath export (`files-sdk/r2`, `files-sdk/gcs`, …) and runs the same methods, so switching providers means swapping the adapter and nothing else. Its provider's SDK is an optional peer dependency, so the adapters you never import are never bundled.

Each adapter's page covers installation, the options it takes, and a compatibility table for anything the provider does differently. The [provider catalog](/docs/providers) has the same list as data, with the environment variables each adapter reads.
